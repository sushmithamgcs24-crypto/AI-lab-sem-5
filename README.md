# BMS College of Engineering, Bangalore-19
## Department of Computer Science and Engineering
### Course Portfolio: Artificial Intelligence Laboratory (23CS5PCAIN)

This repository contains the complete portfolio of laboratory implementations for the 5th-semester core course **Artificial Intelligence** (Course Code: **23CS5PCAIN**). 

The project features a weekly collection of foundational AI algorithms developed in Python 3. Each module is structured to demonstrate key artificial intelligence paradigms, including state space search strategies, intelligent reflexive agents, heuristic global optimization techniques, and formal logical reasoning models.

---

## 🛠️ Repository Highlights
*   **Prefix Structure:** All core lab submissions are tracked weekly and tagged with the student identification USN (`1WN24CS295`).
*   **Pure Python:** Built entirely using native Python standard libraries (`math`, `random`, `re`) without third-party framework overhead.
*   **Academic Alignment:** Designed and tested to fulfill the Continuous Internal Evaluation (CIE) milestones and practical runtime verification cases mandated by the department guidelines.

## 💻 How to Run
Ensure you have Python 3.x installed on your environment. Clone the repository and execute any script directly via the command line interface:

```bash
git clone https://github.com
cd AI-lab-sem-5
python week5/1WN24CS295_Week5_SimulatedAnnealing.py
```
